# 📇 Anki English Cards

Минималистичный мобильно-адаптивный веб-сервис для изучения английских слов методом флеш-карточек Anki с возможностью пополнения словаря через JSON и автоматической синхронизацией в GitHub.

## Возможности

- **Интерактивные карточки Anki:**
  - Лицевая сторона — английское слово, обратная — перевод на русский.
  - Плавная 3D-анимация переворота по тапу/клику.
  - Перемешивание колоды (Shuffle), переход к предыдущему/следующему слову, счетчик прогресса.
  - Горячие клавиши на десктопе: `Space` / `Enter` — перевернуть, `←` / `A` — назад, `→` / `D` — вперед.
- **Импорт новых слов (JSON):**
  - Поддерживается формат:
    ```json
    [
      { "en": "clean", "ru": "чистый" },
      { "en": "improve", "ru": "улучшать" }
    ]
    ```
  - Автоматическая валидация синтаксиса и дедупликация слов (case-insensitive + trim пробелов).
- **Синхронизация через GitHub API:**
  - Прямой коммит обновленного `public/words.json` в репозиторий через GitHub Contents API.
  - Токен доступа (PAT) хранится **исключительно локально** в браузере пользователя (`localStorage`).
  - Резервный режим: если токен не задан, новые слова сохраняются в локальном кэше браузера.
- **Публикация через GitHub Pages:**
  - Настроен готовый GitHub Actions workflow (`.github/workflows/deploy.yml`).

## Настройка и публикация на GitHub Pages

1. **Создайте репозиторий на GitHub** и запушьте в него проект:
   ```bash
   git remote add origin https://github.com/<ваш-логин>/<имя-репозитория>.git
   git branch -M main
   git push -u origin main
   ```
2. **Включите GitHub Pages в настройках репозитория:**
   - Перейдите в **Settings** → **Pages**.
   - В секции **Build and deployment** выберите **Source: GitHub Actions**.
   - При каждом пуше в ветку `main` проект будет автоматически собираться и развертываться.

## Настройка синхронизации словаря (GitHub PAT)

Чтобы добавлять слова со смартфона или компьютера прямо в репозиторий:

1. Перейдите в GitHub: **Settings** → **Developer Settings** → **Personal Access Tokens** → **Fine-grained tokens** (или Tokens classic).
2. Выберите ваш репозиторий и выдайте право:
   - **Repository permissions** → **Contents** → **Access: Read and write**.
3. Скопируйте созданный токен.
4. Откройте сайт, нажмите кнопку **⚙️ (Настройки)**:
   - Вставьте токен в поле **GitHub PAT**.
   - Укажите **Владельца** (`username`) и **Имя репозитория** (`repo-name`).
   - Нажмите **«Проверить связь»** и затем **«Сохранить»**.

## Локальная разработка

Для локального запуска используется `bun` или `mise`:

```bash
# Установка зависимостей
bun install

# Запуск dev-сервера
mise run dev
# или
bun run dev

# Сборка проекта
mise run build
# или
bun run build
```
